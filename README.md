## Overview

The system implements mathematical operations over
signals using operational amplifier circuits.


## Implemented Circuits

### Integrator Circuit

Function:
Signal integration


### Differentiator Circuit

Function:
Signal differentiation


## Hardware

- Operational Amplifiers
- Resistors
- Capacitors
- Oscilloscope
- Signal Generator


## Software Integration

Processed signals are captured and visualized
through the a wave visualizer desktop application.


## System Architecture

Signal Generator
 ↓
Analog Processing Circuit
 ↓
Oscilloscope Visualization
